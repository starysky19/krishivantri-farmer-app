# Krishivantri — Farmer App

**Krishivantri** is an agriculture-focused mobile application that enables farmers to select their farmland boundaries using a polygon tool, get instant pricing, book drone spraying services so a drone pilot arrives at their location to spray and complete the job, and order organic medicines available on the platform whenever needed.

## Key Features

- **Polygon Farmland Selection:** Farmers draw a polygon around their exact farmland boundaries on the map to calculate land area.
- **Instant Pricing:** Displays transparent spraying costs upfront based on the selected farmland.
- **Drone Spraying Booking:** Farmers book a spraying service and a drone pilot arrives at their location, completes the spraying, and goes.
- **Organic Medicine Ordering:** Browse and order organic medicines available on the platform whenever needed.
